# LoanWatch 操作手順書

この手順書は、Python を使ったことがない方でも LoanWatch を使えるように、セットアップから実行、選手設定の追加・編集・削除までを説明します。

## 1. セットアップ

配布されたファイルを、同じフォルダに置いてください。

```text
LoanWatch.exe
players.json
```

`LoanWatch.exe` がアプリ本体です。Python のインストールは不要です。

`players.json` は選手設定ファイルです。選手を追加・編集・削除すると、このファイルが更新されます。

おすすめの置き場所の例:

```text
デスクトップ\LoanWatch\
```

最初の起動時は、アプリ内部のファイル展開やウイルス対策ソフトの確認で少し時間がかかることがあります。

Windows の警告が出た場合は、配布元が信頼できることを確認したうえで、必要に応じて `詳細情報` から実行してください。

## 2. アプリの起動

1. `LoanWatch.exe` をダブルクリックします。
2. `LoanWatch` という画面が開きます。
3. 画面に `実行設定` と `実行ログ` が表示されます。

`players.json` が同じフォルダにない場合は、設定ファイルが見つからないエラーが表示されます。その場合は、`LoanWatch.exe` と同じフォルダに `players.json` を置き直してください。

## 3. 試合出場状況の取得手順

1. `シーズン` を選択します。
2. `出力ファイル名` を入力します。
   - 例: `loan_players_latest`
   - 拡張子 `.xlsx` や `.csv` は入力しなくて大丈夫です。
3. `出力形式` を選びます。
   - `Excel`: Excel ファイルを作成します。
   - `CSV`: CSV ファイルを作成します。
   - どちらか1つ以上を選択してください。
4. `実行` ボタンをクリックします。
5. `実行ログ` に進行状況が表示されます。
6. 完了すると、`LoanWatch.exe` と同じフォルダに結果ファイルが作成されます。

例:

```text
loan_players_latest.xlsx
loan_players_latest.csv
```

シーズンの選択肢は日付に応じて自動で制御されます。2027年6月までは `2026/27シーズン` のみ選択できます。

処理を途中で止めたい場合は、`停止` ボタンをクリックします。

## 4. 選手設定画面を開く

1. LoanWatch のメイン画面で `選手設定を編集` ボタンをクリックします。
2. `players.json editor - players.json` という画面が開きます。
3. 上側に登録済み選手の表、下側に設定フォームが表示されます。

設定フォームでは、最初に `source` を選択します。

| 表示名 | 内部的な意味 | 対象 |
|---|---|---|
| Jリーグ | football-lab | Jリーグ所属選手 |
| 海外リーグ | espn | 海外リーグ所属選手 |

## 5. Jリーグ選手の追加手順

1. 表の下にある `選択解除` をクリックします。
   - 追加するときは、既存の行が選択されていない状態にします。
2. `source *` で `Jリーグ` を選択します。
3. `選手名(日本語) *` を入力します。
   - 例: `山田太郎`
4. `選手名(英語)` を入力します。
   - 分かる場合は入力してください。
5. `クラブ *` のドロップダウンから所属クラブを選択します。
6. `Football-LAB URL *` が自動で入力されます。
7. `選手名(日本語)` の入力後、約3秒待つと `Jリーグ公式URL` の自動検索が行われます。
8. `Jリーグ公式URL` が入ったことを確認します。
   - 見つからない場合は空欄のままでも追加できますが、出場時間などの補完精度が下がることがあります。
9. `追加` ボタンをクリックします。
10. 表に選手が追加されたことを確認します。
11. 最後に `JSON保存` をクリックします。

Jリーグ選手で必須なのは、`source`、`選手名(日本語)`、`クラブ`、`Football-LAB URL` です。

## 6. 海外選手の追加手順

1. 表の下にある `選択解除` をクリックします。
2. `source *` で `海外リーグ` を選択します。
3. `選手名(日本語) *` を入力します。
   - 例: `山田太郎`
4. `選手名(英語)` を入力します。
   - 海外リーグでは必須です。
   - 例: `Taro Yamada`
5. `クラブ *` を入力します。
   - 例: `Leeds United`
6. `選手名(英語)` の入力後、約3秒待つと ESPN の選手URL検索が行われます。
7. `ESPN URL *` が自動で入力されたことを確認します。
8. 自動で見つからない場合は、ESPN の選手ページURLを手入力します。
   - URL の中に `/id/数字/` が含まれていれば、ESPN ID は自動で読み取られます。
9. `追加` ボタンをクリックします。
10. 表に選手が追加されたことを確認します。
11. 最後に `JSON保存` をクリックします。

海外選手で必須なのは、`source`、`選手名(日本語)`、`選手名(英語)`、`クラブ`、`ESPN URL`、`ESPN ID` です。ESPN ID は通常、ESPN URL から自動で取得されます。

## 7. 既存選手の編集手順

1. 上側の `登録選手` の表から、編集したい選手の行をクリックします。
2. 下側の設定フォームに、その選手の内容が表示されます。
3. 必要な項目を修正します。
   - Jリーグ選手は、クラブを変更すると `Football-LAB URL` も連動して変更されます。
   - 選手名を変更すると、Jリーグ公式URLやESPN URLの再検索が行われる場合があります。
4. `行を上書き` ボタンをクリックします。
5. 表の内容が更新されたことを確認します。
6. 最後に `JSON保存` をクリックします。

`行を上書き` をクリックしただけでは、まだ `players.json` には保存されません。必ず最後に `JSON保存` をクリックしてください。

## 8. 既存選手の削除手順

1. 上側の `登録選手` の表から、削除したい選手の行をクリックします。
2. `削除` ボタンをクリックします。
3. 確認メッセージが表示されます。
4. 削除してよければ `はい` をクリックします。
5. 表から選手が消えたことを確認します。
6. 最後に `JSON保存` をクリックします。

`削除` をクリックしただけでは、まだ `players.json` には保存されません。削除を確定するには `JSON保存` が必要です。

## 9. JSON の保存とバックアップ

選手設定を追加・編集・削除した後は、必ず `JSON保存` をクリックしてください。

`JSON保存` をクリックすると、次の2つが行われます。

1. 現在の `players.json` がバックアップされます。
2. 新しい内容で `players.json` が上書き保存されます。

バックアップファイル名の例:

```text
players_20260811_064539.backup.json
```

バックアップは、`players.json` と同じフォルダに作成されます。

保存前に画面を閉じようとすると、未保存の変更があることを知らせる確認メッセージが表示されます。

間違えて保存した場合は、バックアップファイルを使って戻すことができます。戻す場合は、現在の `players.json` を別名で残してから、戻したいバックアップファイルを `players.json` という名前に変更してください。

## 10. Excel ファイルの説明

Excel を選択して実行すると、`.xlsx` ファイルが作成されます。

Excel は見やすくなるように、次の整形が入っています。

- 列幅は内容に合わせて自動調整されます。
- ヘッダー行は薄い水色です。
- 偶数行はごく薄いグレーです。
- 1行目は固定されています。
- フィルターが有効になっています。

出力される主な列は次のとおりです。

| 列名 | 内容 |
|---|---|
| 選手 | 選手名 |
| クラブ | 所属クラブ |
| 日付 | 取得できた最新試合の日付 |
| 経過 | その試合が何日前か |
| ステータス | 先発、途中出場、ベンチ入りのみ、ベンチ外、試合なしなど |
| 出場時間 | 出場時間または途中出場の情報 |
| 試合 | 対戦相手 |
| 試合結果 | 対象クラブ視点の勝敗・スコア |
| ゴール数 | ゴール数 |
| 警告/退場 | 警告数と退場数 |
| 備考 | 取得時の補足や注意 |
| URL | 参照元URL |

ステータスの見方:

| ステータス | 意味 |
|---|---|
| 先発 | スタメン出場 |
| 途中出場 | ベンチから途中出場 |
| ベンチ入りのみ | ベンチ入りしたが出場なし |
| ベンチ外 | メンバー外、招集外など |
| 試合なし | 対象シーズンの試合情報を取得できない、または試合が見つからない |

`備考` に注意が出ている場合は、サイト側の更新遅れ、通信エラー、データ未掲載などが考えられます。

## 11. CSV ファイルの説明

CSV を選択して実行すると、`.csv` ファイルが作成されます。

CSV は Excel 以外のツールでデータを使いたい場合に便利です。通常の確認用途では、見やすく整形されている Excel の利用がおすすめです。

## 12. よくある困りごと

### アプリが起動するまで時間がかかる

初回起動時や、ウイルス対策ソフトが確認しているときは時間がかかることがあります。しばらく待ってください。

### `players.json` が見つからないと表示される

`LoanWatch.exe` と `players.json` が同じフォルダにあるか確認してください。

### URL が自動入力されない

選手名の表記ゆれや、検索サイト側の結果によって自動入力できないことがあります。数秒待っても入らない場合は、公式サイトやESPNのURLを手入力してください。

### 実行結果にエラーが出る

インターネット接続、対象サイトの一時的な不調、サイト側のデータ未更新などが原因になることがあります。時間を置いて再実行してください。

### 選手を追加したのに次回起動時に消えている

`追加` の後に `JSON保存` をクリックしていない可能性があります。追加・編集・削除の後は、必ず `JSON保存` をクリックしてください。
